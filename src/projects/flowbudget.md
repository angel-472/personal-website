FlowBudget is a web app I built because I needed to streamline my manual budgeting workflow, which I used to manage in Apple Notes. However, it was difficult to keep up to date, and I constantly had to recalculate my expenses and income. Thanks to this simple web app, I can now track my expenses and income in a way that is easy to use while keeping my financial data organized.

I have made the demo public, so if anyone feels this app suits their needs, they are welcome to use it. The app has full PWA support, which means you can add it to your phone's home screen for quick access.

I started this project in October 2025 with the help of AI tools to quickly build a prototype. However, since then, I have been rewriting it to ensure the codebase is clean, maintainable, and scalable.
